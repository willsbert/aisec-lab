> 用法：跑完 D2-D6 后逐项填写"实验证据"列，标注影响级与缓解措施。
> 等级：高 / 中 / 低。

| OWASP 项 | 风险描述 | 涉及靶标 | 实验证据 | 影响级 | 缓解措施 |
|---|---|---|---|---|---|
| LLM01 提示词注入 | 直接/间接注入 | A / B / C | D2 inj-06 翻译绕过、jail-03 编码混淆（reports/d2_results.json）；D3 文档投毒（reports/d3_poison_results.md）；D6 工具注入 | 高 | 指令分隔、输入过滤、工具结果隔离 |
| LLM02 敏感信息泄露 | 提示词/数据泄露 | B / C | D3 越权检索 root 密码（reports/d3_poison_results.md）；D6 记忆泄露 Mem0-12345 | 高 | 输出校验、日志脱敏、最小权限 |
| LLM03 供应链 | 依赖/权重风险 | 全部 | D11 待跑（SBOM + hash） | 中 | pip-audit、SBOM、权重 hash 校验 |
| LLM04 数据与模型投毒 | LoRA 后门 | 工具 | D5 触发词后门生效（蓝月亮→FLAG-2026-SECRET） | 高 | adapter 来源审计、权重校验、沙箱 |

## 优先级排序（修复建议）

1. LLM06 过度代理（高危）：权限矩阵 + 审批流（D7 已实现 main_hardened.py）
2. LLM01/LLM05 注入与输出处理（高危）：D4 防护 + 工具结果隔离
3. LLM04 投毒（高危）：adapter 校验流程
4. LLM02/LLM07 泄露（中高）：输出校验 + 日志脱敏
5. LLM08（中）：文档分级
6. LLM10（中）：步数上限
